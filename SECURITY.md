# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Instead, use GitHub's private vulnerability reporting flow for this repository if it is enabled. If private reporting is unavailable, contact the repository owner directly through GitHub and include:

- A clear description of the issue
- The affected code path or file
- Steps to reproduce
- Impact assessment
- Any suggested mitigation, if available

Please avoid posting proof-of-concept details publicly until the issue has been reviewed and a fix or mitigation is available.

## Response Guidelines

The maintainer will try to:

- Acknowledge receipt of a report within a reasonable time
- Reproduce and assess the issue
- Prepare a fix or mitigation when appropriate
- Credit the reporter if they want public acknowledgment

## Supported Versions

Security fixes are handled on the current mainline codebase in this repository.
